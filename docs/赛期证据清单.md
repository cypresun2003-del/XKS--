## 〇、为什么 AI 工具记录比 Git 历史更值得采信

Git 的提交时间可以被本地系统时间随意修改，事后补造一段「看起来很自然」的提交历史在技术上没有门槛。

而 AI 编程工具的会话记录具备以下特点：

1. **由工具服务端自动生成、逐条写入**，用户无法事后编辑单条历史而不留痕迹
2. **每条记录带精确到毫秒的时间戳（UTC）**
3. **完整记录了"用户说了什么 → AI 做了什么 → 产生了什么文件 → 运行了什么命令 → 返回了什么结果"的全过程**
4. **包含当时用户上传的截图文件名与临时路径**——这些临时文件已不存在，无法事后伪造

因此，**邀请评委优先核查 A 类证据**。
